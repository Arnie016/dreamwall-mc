# AfterBlock generated texture set

Generated 3200 Minecraft-style item textures, 3D item model JSON files, material finishes, variant display profiles, a resource-pack skeleton, contact sheets, and a browser gallery.

- Gallery: `assets/afterblock_textures/gallery/index.html`
- Report: `assets/afterblock_textures/gallery/library_report.json`
- Contact sheets: `assets/afterblock_textures/gallery/contact_sheet_01.png` through `assets/afterblock_textures/gallery/contact_sheet_32.png`
- Resource pack: `resource-pack/AfterBlockMuseum/`
- Manifest: `assets/afterblock_textures/afterblock_manifest.json`
